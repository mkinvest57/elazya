Bienvenue sur Alizé

Alizé est votre assistant personnel local, conçu pour respecter votre vie privée tout en augmentant votre productivité de manière exponentielle.

🚀 En Bref : Alizé tourne 100% sur votre machine. Elle utilise Gemini 2.5 Flash pour une rapidité extrême et peut interagir avec vos fichiers, votre terminal et vos applications.

Installation Rapide

Copiez-collez cette commande dans votre terminal pour installer Alizé (Mac/Linux) :

BASH
curl -sL https://get.alize.ai/install | bash

Premier Lancement

Une fois installé, lancez simplement :

BASH
alize start

L'interface web s'ouvrira automatiquement à l'adresse http://localhost:3000.
