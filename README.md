# 🌬️ Alizé - Le Premier Agent IA Français Haute Performance



**Alizé** est un assistant IA personnel open source qui fonctionne sur votre ordinateur. Il connecte les principaux fournisseurs d'IA (Claude, ChatGPT, Gemini) aux canaux de messagerie (WhatsApp, Telegram, iMessage, Discord, Slack, Signal) et outils de productivité.

## ✨ Caractéristiques

- 🤖 **Multi-providers IA** : Google Gemini (GRATUIT), Claude, GPT-4, modèles locaux
- 💬 **Multi-canaux** : WhatsApp, Telegram, iMessage, Discord, Slack, Signal, LINE
- 🛠️ **Skills extensibles** : Email, Calendrier, Météo, Musique, Domotique...
- 🖥️ **Interface TUI** : Interface terminal interactive
- 🌐 **API Gateway** : REST API pour intégrations
- 🔒 **100% local** : Vos données restent chez vous

## 🚀 Installation Rapide

```bash
# Cloner et installer
git clone https://github.com/votre-repo/alize.git
cd alize
./installer_alize.sh
```

## 📖 Utilisation

```bash
# Démarrer Alizé
alize daemon start

# Voir le statut
alize daemon status

# Liste des skills
alize skills list

# Interface terminal
alize tui
```
