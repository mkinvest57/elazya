Installation en 30 secondes

Obtenez votre clé API Gemini et lancez Alizé

1

Créez votre clé API

Rendez-vous sur Google AI Studio et cliquez sur "Get API Key".

aistudio.google.com/apikey →
2

Installez Alizé

Téléchargez et exécutez l'installateur :

./installer_alize.sh
3

Configurez et lancez

Suivez l'assistant de configuration :

alize onboard
4

C'est prêt !

alize daemon start
